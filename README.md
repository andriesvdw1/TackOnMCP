# TackOnMCP

## Setup in LMStudio Bionic
Open settings
Click on MCP
Name "TackOn"
Connection click on "On this computer"
Command "C:\\Users\\Admin\\Desktop\\TackOnMCP\\.venv\\Scripts\\python.exe" Replace "Admin" with your username
Toggle show advanced options to be on
Arguments "C:\\Users\\Admin\\Desktop\\TackOnMCP\\server.py"
Working directory "C:\Users\Admin\Desktop\TackOnMCP"

## Dependencies
pip install "mcp[cli]"
pip install uv

## Python version required
Python 3.4 or later for using the pathlib library to create files.
